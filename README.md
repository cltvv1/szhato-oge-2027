# СЖАТО — подготовка к изложению ОГЭ

Интерактивный курс для девятиклассников по программе Анны Кроневальд:
редактируемая теория с тестами, практические тренажёры, аудиокаталог,
сохранение прогресса, экзаменационный режим с двумя прослушиваниями и кабинет
учителя для проверки работ.

Полный контекст проекта и инструкция для продолжения работы на другом компьютере находятся в [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md). Исходная тетрадь и подготовленные версии для учеников и педагогов собраны в каталоге [`materials/`](materials/).

## Что понадобится

- [Git](https://git-scm.com/downloads)
- [Node.js](https://nodejs.org/) версии 22.13 или новее

## Запуск на своём компьютере

```bash
git clone https://github.com/cltvv1/szhato-oge-2027.git
cd szhato-oge-2027
npm install
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000).

## Основные команды

```bash
npm run dev      # локальный сервер с автоматическим обновлением
npm run build    # проверка сборки перед публикацией
```

## Где что находится

- `app/page.tsx` — главная страница;
- `app/theory/` — интерактивные уроки и тесты после уроков;
- `app/practice/` — упражнения по редактируемым направлениям;
- `app/audio/` — свободный аудиотренажёр с заметками и случайным текстом;
- `app/admin/` — защищённая панель автора для всего учебного контента;
- `app/student/` — вход ученика по персональному коду, оценки и комментарии;
- `app/api/` и `lib/` — вход, загрузка аудио и динамические реестры;
- `app/simulator/` — экзаменационный режим;
- `app/data.ts` — тексты уроков, задания и ответы-ориентиры;
- `app/globals.css` — оформление сайта;
- `public/` — изображения и иконки.

Обычные черновики и отметки прогресса остаются локальными в браузере. Ученик
может войти по персональному коду и явно отправить выбранную работу учителю;
такие работы, оценки и комментарии доступны в его кабинете на разных
устройствах. Записи кабинета шифруются перед сохранением в Vercel Blob.

Уроки, тесты, направления практики, задания и единая библиотека аудио хранятся в Vercel Blob. В `/admin` автор может добавлять и редактировать весь этот контент, создавать учеников, выдавать им коды и проверять работы. Одну аудиозапись можно включить в свободный тренажёр, экзаменационный режим или в оба раздела. Для работы панели нужны переменные `BLOB_READ_WRITE_TOKEN`, `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`. Для кабинета рекомендуется также задать отдельный длинный `CLASSROOM_SECRET`; без него используется `ADMIN_SESSION_SECRET`. В production переменные задаются в Vercel; для локальной разработки после привязки проекта выполните `npx vercel env pull .env.local`.
