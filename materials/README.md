# Материалы рабочей тетради

Все материалы относятся к программе подготовки к сжатому изложению ОГЭ-2027. Автор — Кроневальд Анна Андреевна.

## Файлы

- `Idealnoe_izlozhenie_original.docx` — исходный авторский файл. Не редактировать и не перезаписывать; использовать как контрольный оригинал.
- `Idealnoe_izlozhenie_redaktura_OGE-2027.docx` — промежуточная общая редакционная версия.
- `Idealnoe_izlozhenie_OGE-2027_dlya_uchenikov.docx` — финальная редактируемая версия для учеников.
- `Idealnoe_izlozhenie_OGE-2027_dlya_uchenikov.pdf` — версия для просмотра и печати учениками, 56 страниц.
- `Idealnoe_izlozhenie_OGE-2027_dlya_pedagogov.docx` — финальная редактируемая версия для учителей и репетиторов.
- `Idealnoe_izlozhenie_OGE-2027_dlya_pedagogov.pdf` — версия для просмотра и печати педагогами, 81 страница.

## Правила дальнейшей работы

1. Оригинал хранить неизменным.
2. Новые редакции сохранять под новым понятным именем или отдельным коммитом.
3. После изменений в DOCX экспортировать соответствующий PDF заново.
4. Проверять все страницы визуально: рамки, переносы, текстовые поля, стрелки, колонтитулы и номера страниц.
5. Перед публичным или коммерческим распространением подтвердить права на тексты и графику и сверить методику с окончательными материалами ФИПИ-2027.

Репозиторий публичный: эти файлы доступны для скачивания всем, у кого есть ссылка на GitHub.
