# Контекст проекта «СЖАТО»

Этот файл нужен для бесшовного продолжения работы в Codex на другом компьютере. В новом чате сначала попросите Codex прочитать этот файл, `README.md` и каталог `materials/`, затем проверить `git status` и продолжить работу с актуальной веткой `main`.

## Суть проекта

- Проект: интерактивная подготовка девятиклассников к сжатому изложению ОГЭ по русскому языку.
- Рабочее название продукта и сайта: «СЖАТО».
- Автор программы и рабочей тетради: Кроневальд Анна Андреевна.
- Целевой экзаменационный цикл: ОГЭ-2027.
- Исходная методическая основа: авторская рабочая тетрадь Анны.
- Текущий формат продукта: печатные/электронные материалы плюс бесплатный браузерный прототип.

### Сайт

Реализован адаптивный сайт на Next.js с разделами:

- `/` — главная страница;
- `/theory` — шесть коротких теоретических уроков;
- `/practice` — 26 интерактивных упражнений;
- `/simulator` — экзаменационный тренажёр.

Ответы и прогресс сейчас сохраняются только в `localStorage` браузера. Аккаунтов, базы данных, синхронизации между устройствами и кабинета преподавателя пока нет.

Основные файлы:

- `app/page.tsx` — главная;
- `app/theory/page.tsx` — теория;
- `app/practice/page.tsx` — упражнения;
- `app/simulator/page.tsx` — тренажёр;
- `app/data.ts` — содержание уроков, упражнений и ответов-ориентиров;
- `app/components/AppShell.tsx` — общий каркас и навигация;
- `app/globals.css` — визуальное оформление.

## Как продолжить дома

Требуются Git и Node.js версии 22.13 или новее.

```bash
git clone https://github.com/cltvv1/szhato-oge-2027.git
cd szhato-oge-2027
npm install
npm run dev
```

Локальный адрес после запуска: <http://localhost:3000>.

Перед началом каждой сессии:

```bash
git pull --ff-only
git status
```

После изменений:

```bash
npm run build
git add <изменённые-файлы>
git commit -m "Краткое описание изменений"
git push origin main
```

Vercel подключён к GitHub: успешный push в `main` автоматически создаёт новую production-публикацию.

## Технические решения и ограничения

- Основной production-фреймворк: Next.js 16, React 19, TypeScript.
- Публикация: Vercel, без отдельного арендуемого сервера.
- В `package.json` остались вспомогательные команды `sites:dev` и `sites:build` от раннего прототипа; основной запуск — `npm run dev`, основная сборка — `npm run build`.
- Для правок DOCX лучше использовать Microsoft Word или LibreOffice и обязательно проверять результат через экспорт в PDF/постраничный рендер.
- LaTeX для этой тетради не обязателен: Word удобнее для сложной визуальной верстки, текстовых полей, фигур и дальнейшего редактирования автором. LaTeX имеет смысл только при полном переиздании в более строгой типографской системе.
- Файлы Word/PDF достаточно крупные, но каждый находится значительно ниже ограничения GitHub в 100 МБ.
